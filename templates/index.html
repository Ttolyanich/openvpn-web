2. Маршрутизация и DNS (Push директивы)

Перенаправлять весь интернет-трафик (Default Gateway) Директива push "redirect-gateway def1 bypass-dhcp". Клиенты выходят в интернет через шлюз VPN.
Клиенты видят друг друга (client-to-client) Директива client-to-client. Разрешает прямой обмен пакетами между клиентами внутри туннеля.
Игнорировать маршрут подсети VPN на клиентах (route-nopull) Директива push "route-nopull". Клиенты не перехватывают всю подсеть VPN, а направляют трафик только в явно добавленные маршруты.
Клиенты автоматически получат маршруты в указанные сети через туннель

3. Изоляция Windows Wintun (dev-node)

Использовать изолированный сетевой адаптер Windows (dev-node) Фиксирует имя виртуального адаптера Wintun, защищая от конфликтов с параллельно установленными VPN.
При выключении тумблера директива dev-node исключается из конфигураций клиентов.
